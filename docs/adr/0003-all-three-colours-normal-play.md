# All three colours in normal play; two-of-three is the hard mode

`DESIGN.md` specified picking two of the three colours before each level, on the grounds that it changes both how you fight and which routes are open, and claimed replay value from doing so. We reversed that: all three colours are always available in normal play, and two-of-three becomes an unlockable hard mode instead.

## Status

Accepted. Supersedes the loadout requirement in `DESIGN.md:19`; the replay claim in `DESIGN.md:112` is preserved by the hard mode rather than by the default.

## Considered Options

Two-of-three for every level, as originally written. It does create routing problems, but it forces the player to learn the colour system *and* a restriction at the same time, and a player who left the wrong colour at home meets an unsolvable-feeling wall rather than a puzzle.

Two-of-three as an outright second campaign. Rejected as scope with no content to fill it.

## Consequences

- Armour shells (`DESIGN.md:45`) lose their original purpose, since they existed to turn a missing colour into a routing problem. They need re-evaluating rather than carrying over.
- Replayability now comes from a mode toggle plus scored runs, which is far cheaper than building alternative levels for each colour pairing.
- The colour system has to carry itself on tactical choice alone in normal play, so the shared tank and grey-as-enemy-paint decisions are doing the work the loadout restriction used to do.
